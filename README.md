# 休行 · LeaveFlow

中文请假管理交互演示，纯 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## 功能

- 员工和主管两种演示身份
- 提交、查看和撤回请假申请
- 通过或驳回申请，并自动更新演示余额
- 按姓名、单号、事由、假期类型和审批状态筛选
- 年假、调休余额和团队休假日历
- 适配桌面与移动端

## 本地运行

在项目目录运行 `python3 -m http.server 8080`，然后打开 `http://localhost:8080`。

## 部署说明

仓库保持私有。当前尚未启用网站发布。

此项目可部署到静态托管平台，无需构建步骤；`.nojekyll` 支持直接发布静态文件。

注意：私有 GitHub 仓库与私有网站是两回事。个人账号从私有仓库使用 GitHub Pages 需要 GitHub Pro，而且网站默认对互联网公开。访问受限的私有 Pages 适用于 GitHub Enterprise Cloud 组织拥有的私有或内部仓库。发布前应确认预期访问范围和托管方案，不要为了上线而将仓库改为公开。

## 演示范围与数据

- 所有公司、人物与初始记录均为虚构
- 操作只保存在当前浏览器的 localStorage，不上传至服务器，也不跨设备同步
- 没有真实登录、身份校验、权限隔离或多人协作后台；身份切换仅用于演示
- 请勿输入真实员工资料或敏感信息
- 演示日期固定为 2026 年 9 月 30 日，申请范围截至 2026 年 12 月 31 日
- 时长仅计算周一至周五，未接入法定节假日或调休规则，不能作为真实人事核算依据
- 页面底部的“重置演示”可恢复初始虚构数据

## 文件

- `styles.css`：响应式界面样式
- `app.js`：演示数据与交互逻辑
